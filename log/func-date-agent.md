- Key design idea (decision FD-1 below): floor division by a constant d of an integer x is done as q = ROUND(c x + b) with c close to 1/d and b close to -0.5 + 0.5/d. For integer x, x/d has fractional part in [0, (d-1)/d], so c x + b lies at least 0.5/d away from every half integer and ROUND gives floor(x/d). Constants need only about 8 significant digits for the ranges used (|x| < 4e6), so all constants can be worked out by hand with long division, and each floor costs one dense row plus the 2-row ROUND.
