## 2026-11-06 session 2, reading and plan (CRC-32, ZIP, inflate, deflate)
- Reread AGENT_BRIEF (with Updates: block payload networks always output mem_op 3; no sed on .wt), RULES, FORMAT, control.md, functions.md (the worksheet ABI does not apply to these subsystem routines; they use the control.md subroutine convention with registers documented per network), memory-map (FILE_SCRATCH 0x3B0000..0x3BFFFF).
- Key building block decided first: 32-bit XOR. Neither relu nor step gives bits in parallel cheaply (a dense layer is full, so lane-parallel elementwise work costs n^2 typed weights). So one network (x32) decomposes U and V together top-down, one bit level per 6 layers (threshold, step, AND product by a mul layer, update of [rU, rV, acc]), 32 levels; XOR = U + V - 2 AND. About 930 typed numbers, typed once and called as a leaf by everything that needs XOR.
- CRC-32 table-driven: crc' = T[(crc mod 256) XOR b] XOR floor(crc / 256). The 8-bit XOR is done in the crc network itself (8 levels), the 32-bit XOR in x32, which also reads the next data byte for the crc network, so 2 steps per byte. Table: generator network (rule 3 style, but it writes data, not weights): T[i] = T[2^j] XOR T[i - 2^j] with 2^j the highest bit of i; the 8 basis values T[1], T[2], ..., T[128] are worked out by hand below and typed as constants.
- Hand derivation of the basis (reflected polynomial P = 0xEDB88320, one round: c = c >> 1, XOR P if the dropped bit was 1). T[128]: seven even rounds then c = 1 -> P = 0xEDB88320. T[64]: rounds give P then P even -> P >> 1 = 0x76DC4190. T[32] = 0x3B6E20C8. T[16] = 0x1DB71064. T[8] = 0x0EDB8832. T[4] = 0x076DC419. T[2]: 0x076DC419 is odd -> 0x03B6E20C XOR 0xEDB88320 = 0xEE0E612C. T[1] = 0x77073096. (T[1] and T[2] agree with the published table entries 1 and 2.)
- Decimal: P 3988292384, 0x76DC4190 = 1994146192, 0x3B6E20C8 = 997073096, 0x1DB71064 = 498536548, 0x0EDB8832 = 249268274, 0x076DC419 = 124634137, 0xEE0E612C = 3993919788, 0x77073096 = 1996959894.
- Inflate plan: (1) expand the compressed bytes into one bit per word (LSB first, the DEFLATE order), 2 steps per byte; then every "read n bits" is one block read at the bit pointer BP. (2) Canonical Huffman tables (count, offsets, symbols) built from code lengths by a builder loop (puff style). (3) Decoding a symbol in one forward pass: a block read of cnt[0..15], then a block read of the next 15 bits forwarded with the counts (K = 79), then one unrolled consumer: code_l, first_l, index_l are linear in bits and counts, found_l = step(cnt_l + first_l - code_l - 0.5), first found level by a triangular dense, symbol index by a mul and a sum. Then a read of the symbol. Length and distance base and extra-bit tables are written once by a constants network.
- Generic helpers to save ids: BRD (block read with address, count, next id and PC taken from T7..T10) and BZ (block write of 64 zeros, looped T9 times).
