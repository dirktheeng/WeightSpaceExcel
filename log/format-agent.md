- Plan (decision F1 in WORKLOG): one shared numeric core for General and custom codes.
  1. fx_dec: |x| -> sign s, decimal exponent e, 15-digit mantissa m in [1e14, 1e15) (Excel's 15 significant digits), in one forward pass, no N x N one-hot matrices (candidate-and-gate trick, notes in fx_dec.md).
  2. fx_rnd: round m half up (decimal, exact integer arithmetic) to the digits the section shows, giving a left-aligned digit stream M and an integer digit count R.
  3. emitter: walks a compiled token list (one token word: code * 65536 + argument) and writes one character per step to an unpacked buffer, peeling digits from M (d = floor(M / 1e14), M = 10 (M - 1e14 d)).
  4. finisher: #### overflow, fill character, pack into a heap string.
  5. General = a planner that picks fixed or scientific and the decimals from the width, then runs the emitter on two fixed token records ("0" conditional point, 10 '#' fraction digits; and the same plus E+00).
  6. Custom codes: a compiler network family turns a code string into a compiled record (sections, conditions, colors, counts, tokens), cached in a format table.
