- Design decision (recorded as AG1 in WORKLOG): the value stream walks a range cell by cell in row-major order with CELL_GET, instead of scanning the whole store like fs_blk. Why: row-major order (Excel's error order, MODE.SNGL first mode, SUMPRODUCT positions) comes for free; the hashed store scan returns cells in hash order and would need a sort. Cost: about 5 steps per cell of the range's area, so small ranges are far cheaper than the 8192-step scan, and whole-column ranges are much slower (documented limit; a hybrid with the store scan is the follow-up).
- Stream format: 2-word entries (TAG, PAY) at EVAL_SCRATCH from SCR (word 56) upward; SCR itself is not advanced by the builder; OUT (word 35) is the end. Mode MD (word 39): 0 numeric aggregate, 1 A-variant, 2 raw non-blank, 3 positional raw (blanks too), 4 logical (AND/OR/XOR). EF (word 18): 1 skips errors (COUNT). C.TAG (word 17) counts reference cells visited. The entry network takes MD, EF, the continuation network and which arguments to stream from a ROM on the fid (T2).
