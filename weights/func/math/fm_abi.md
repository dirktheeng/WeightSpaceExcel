Hand-written. Not generated. Log: log/func-math-agent.md (2026-11-06). Contract: encodings/functions.md (sections 2, 4, 6, 7); the pattern of writing B into the stack and streaming arguments follows the logic agent's lg_arg (weights/func/logic/lg_arg.md).

**fm_ent (277).** Output 66 words; every phase is a block operation (K = 64). PC 0: block write B at [SP, SP + 1], N1 = 1. PC 1: while N1 <= n, block read argument N1 (2 words at SP - 2 (n - N1)) -> fm_arg; then block read 6 words at SP - 2 (n - 1) -> fm_go. PC 2 (back from CELL_GET): block write A over argument N1, re-examine. PC 3 (from fm_arg or ev_t2n): block write fix(A) and N1 += 1; fix keeps tags 0, 1, 3, 4, makes tag 8 (explicit missing) blank and everything else #VALUE! (ranges in scalar positions: implicit intersection is not done).
**fm_arg (278).** Consumer (67 inputs). Tag 9: unpack K = SHEET 2^34 + ROW 2^14 + COL by two FLOORs (address.md section 3) into AS, AR1, AC1, T1 = 0 -> CELL_GET (16), return 277 PC 2. Tag 2: -> ev_t2n (109) with A = (2, handle), return 277 PC 3. Else -> 277 PC 3 with A = the argument.
**fm_go (279).** Consumer (71 inputs). A, B, C = arguments 1..3 (absent: missing (8, 0); absent B is blank for TRUNC, GCD, LCM so TRUNC(x) = ROUNDDOWN(x, 0)). One-hot over the 58 served T2 = 64 + fid values (IS_K pairs, 116 step units), a ROM row each for core id - 258, selector and blank-B flag; unknown fids give core 258 (FN_NAME). Calls the core at PC 0 with LR = 257 (FN_RET), LP = 0, T0 = selector; the core returns into FN_RET with the result in A.
