# SUM (fid 441): fs_sum 30, fs_item 31, fs_cell 32, fs_rng 33, fs_blk 34, fs_uni 35, fs_txt 37

Hand-written. Not generated. ABI: encodings/functions.md. Log: log/abi-agent.md.

**Flow.** fs_sum PC 0 (entry) block-writes argument n at [SP, SP + 1] so all arguments are contiguous, sets CUR (T3, word 32) = first argument, E (T4) = end, W (T5) = work list top = E, ACC (T7, word 36) = 0. PC 1 pops the work list if W > E, else takes the next stack argument, block-reading 2 words into fs_item; when both are exhausted it returns A = (1, 256 ACC) to FN_RET. fs_item dispatches on the tag (11 thresholds, exclusive classes): number or boolean adds 2^-8 PAY; blank or missing is skipped; error returns it; text calls ev_t2n (109) and fs_txt adds the number or returns #VALUE!; tag 9 unpacks K (two FLOORs) and calls CELL_GET (16), fs_cell adds numbers, returns errors, ignores text, booleans and blanks; tag 5 block-reads the range record into fs_rng, which sets lo = S 2^34 + R1 2^14 + 1, hi = S 2^34 + R2 2^14 + 16384, C1, C2 and starts fs_blk on the cell store; tag 10 block-reads the union node and fs_uni pushes both children (left on top). Tags 6, 7 and >= 11 give #VALUE! (arrays not yet).

**fs_blk (the range scanner).** 8 slots per step (block read of 64 words, 8192 steps for the 2^16-slot store). Per lane: COL = (KEY - 1) mod 2^14 by the 1.5 2^52 ROUND and a step correction (exact: (KEY - 1) 2^-14 has at most 50 significant bits); in range iff lo <= KEY <= hi and C1 <= COL <= C2 (four step units, ANDed by mul layers; empty slots (KEY 0) and tombstones (-1) fail lo >= 1). Numbers are scaled by 2^-8 and summed by a pairwise tree of two-term rows (each IEEE add correctly rounded; the scaling is exact for |x| >= 2^-1014). Counts of numbers, nonzero numbers, booleans and TRUE are accumulated for other callers (functions.md section 8b). The first selected error (lowest lane, first block) ends the scan.

**Overflow.** ACC is kept at 2^-8 scale, so |ACC| < 2^1016 means the true sum is finite. The test 2^1023 - 128 ACCn may be -infinity; it feeds only a step layer (value.md V1). Result 256 ACC is exact.

**Excel behaviours covered.** Ranges (reversed corners, whole columns and rows, 3D not yet), unions, intersections (via the evaluator), multiple arguments, missing arguments, direct booleans and numeric text counted, referenced text/booleans/blanks ignored, first error left to right, #NUM! on overflow.

**Limits.** Two different errors inside one range: the one found first in store order is returned, not the first in row-major order. Summation order differs from Excel's left-to-right order (pairwise within 8-slot blocks, store order across blocks); results agree within rounding. Values below 2^-1014 in magnitude lose bits in the 2^-8 scaling. A range scan costs 8192 steps whatever its size (the occupancy list, K-Q3, would make it proportional to the sheet's cells).

**Multi-role weights.** ACC (word 36) is the sum in SUM and the scanner's accumulator, one role at a time. fs_item's vEA row is the error code (tag 4) or the text handle passed to ev_t2n (tag 2), exclusive by tag. fs_blk's PAY lanes feed the sum (number lanes), the error code (error lanes) and the TRUE count (boolean lanes), separated by the tag masks. **Tests.** Stage 1 rng01..rng16, cir07 (14 of 14 through the real manifest), tests/output/func/cases.yaml (14 cases).
