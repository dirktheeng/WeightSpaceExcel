# Weight block notes: General (ids 196, 197, 199)

Hand-written. Not generated. Log: log/format-agent.md "finisher and General"; decision F2.

**fx_gen (196, 1090 params).** After fx_dec. Wc = min(W, 11), W = 0 meaning 11. Fixed when it fits: e >= 0 needs s + e + 1 <= Wc, decimals Wc - s - e - 2 (0 at least); e < 0 uses decimals Wc - s - 2. For e < 0 scientific wins when it shows more digits: capS = ks + 1 > capF = Wc - s - 1 + e and m has more than capF significant digits (m not a multiple of 10^(15 - capF), tested with the exact residual of ROUND(m / D)); ks = Wc - s - 6, minus 1 when abs(e) >= 100 (3 exponent digits). A tie keeps fixed (0.00001 shows 0.00001). Saves m, e, ks, Wc in T5..T8 and calls fx_rnd with T9 = 197.
**fx_gen2 (197, 370 params).** A fixed result whose integer part grew past the width after rounding (99999999999.7) is redone in scientific (m restored from T5). Otherwise writes '-' for negatives, TP = 0xC900 (fixed) or 0xC910 (scientific), NC = 2, T3 = 2 exponent digits, clears T5 (SUB) and starts the emitter.
**fx_init (199, 120 params).** One block write of the two General records, then fx_bi (226): '0', conditional point, ten '#' fraction digits (trailing zeros and the point vanish), and the same followed by E+ and two exponent digits. The token words are hand-computed biases (arg + 65536 code + 2^20 next code).

**Built-in format strings (fx_bi 226, fx_bil 227, fx_bi2 228, fx_bi3 229, fx_bi4 230).** Boot loads the code strings of Excel's en-US built-in ids 1..22 and 37..49 into FMT_TABLE word 0 (ids 23..36 stay 0: Excel has no fixed en-US codes for them). fx_bi: one block write (658 words) at the staging 0xCA00: 36 descriptors [F, start, end] (last 0 0 0) and 550 units typed as character codes; the payload is the biases of a dense layer with 0 input columns, the network's only way to make constants. Loop per string: fx_bil block-reads a descriptor into fx_bi2, which sets the finisher registers as fx_fin does (P0 = start, P1 = end, T0 = len, T1 = T6 = T7 = T8 = 0, LR = fx_bi3) and reads HEAP_TOP; the existing fx_fin2, fx_fin3, fx_pack build the heap string; fx_bi3 writes the handle at 0xC000 + 4 F. At F = 0, fx_bi4 block-writes 658 zeros over the staging (compiled records are later bump allocated there and the compiler expects zeroed memory) and returns to the boot caller saved in AR2, AC2. About 1,900 steps, once. Params: fx_bi 691, fx_bil 16, fx_bi2 213, fx_bi3 24, fx_bi4 682 (zeros included). Precondition: HEAP_TOP (zero page word 1) is set before fx_init runs. Tests: test_builtin_strings, test_builtin_ids (9).

**Limits.** Width in characters, not pixels (Excel fits General by pixel width; open question). Tests: test_general (32 cases including widths 8, 6, 5, 3, 4, 7).
