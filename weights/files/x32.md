# Weight block note: x32 (id 462)

Hand-written. Not generated. Log: log/files-agent.md session 2. Tests: tests/output/files/test_crc.py (test_x32).

**Computes.** T1 = U XOR V with U = x0 + T2 (x0 = the read result the caller requested, T2 an addend the caller sets, usually 0) and V = T1, for integers in [0, 2^32). Then it reads memory at P0 and returns to (LR, LP), so a caller can chain "XOR, then fetch the next byte" in one step. Every other word passes.

**Calling convention.** Leaf subroutine (control.md section 4): next = 462, LR, LP, T1, T2, P0 (address to read). Result in T1, the read result at the caller's next input word 0. Clobbers T1 only.

**Derivation.** XOR = U + V - 2 AND(U, V) and AND = sum_k 2^k u_k v_k. The bits are found top-down in one forward pass: the state r = [rU, rV, acc] goes through 32 levels; level k (w = 2^k) is: dense [rU - (w - 0.5), rV - (w - 0.5)], step (u_k, v_k), mul (u_k v_k), concat, dense [rU - w u_k, rV - w v_k, acc + w u_k v_k]. Thresholds w - 0.5 separate integers exactly; every value is an integer below 2^33, so every row is exact (primitives.md R4). The last dense is [1, 1, 0, 0, 0, -2] over [U, V, 0, 0, 0, AND]. A dense layer is a full matrix, so doing the 32 lanes side by side would cost 32 x 32 typed weights per layer; the serial chain costs 29 numbers per level.

**Parameters.** 979 dense (12 entry, 32 levels of 29, 7 final XOR row, 32 for words 0..7). **Steps.** 1. Depth 199 layers.

**Limits.** U and V must be integers in [0, 2^32); a fractional or larger input gives a wrong (finite) result. **Multi-role weights.** None.
