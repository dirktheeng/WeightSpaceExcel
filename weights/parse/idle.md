# Note: weights/parse/idle.wt (id 66)
Hand-written. Not generated. Shared conventions, register map and limits: weights/parse/README.md. Log: log/parse-agent.md 2026-11-06; decisions P1 to P5 in log/WORKLOG.md.

**Computes.** One step per char between tokens. RDOK 0: read char I (FETCH). Else dispatch on c: space -> skip; digit -> lnum PC 1 (char re-read, TK 1, TO 1, X6 = 73 numconv return id, X7 = 0); '.' -> lnum PC 2 (consumed); letter or '$' -> lword (re-read, X = 0); '"' -> lstr PC 1 (consumed, X4 = SH = HT); '#' -> lerr (consumed); '<' '>' -> lcmp with TO 27 or 29 (consumed); + - -> parse with TK 3, TO 22 or 23; * / ^ & = -> TK 4, TO 20 21 19 24 25; % -> TK 5, TO 18; ( -> TK 6, TO 1; , -> TK 8; ) -> TK 9; end of text -> TK 10; any other char -> reject (79, STATUS + 1).
**Blocks.** 28 thresholds on c_eff give 21 classes. Every output row is a linear map of classes, written over thresholds: the coefficient of t_k is w(class starting at k) - w(class ending at k) (worked by hand row by row; the header comment lists the boundaries). Only FETCH, END and REJECT need step gates (v13). REJECT = RDOK and not END and not any valid class. X4 = HT gated by the quote class (MUX_INT).
**Change 2026-11-06 (session 2).** Apostrophe is a valid class: -> shpack 121 PC 1 with X0 = I + 1, X2 = 1 (gate GQ, which also needs "not intersection"); its next coefficient pair is t39 +48, t40 -48 and the REJECT row lost its t39 +1, t40 -1. Comma TO is 32 (t44 +10, t45 -9), the union opcode, used by parse only when the stack top is a plain '('. TV = I on a letter or '$' (word start, for sheet prefixes). Intersection: SPC (word 28) = GSP = [space and E = 0]; GIL / GIP = [spc and E = 0 and letter, '$', apostrophe / '(']; under GIL + GIP the rows next, TK, TO, mem_op go through relu(row - 2^23 (GIL + GIP)) and then get 73, 4, 33, 0, and I loses the '(' increment, so parse receives a binary operator 33 and the char is dispatched again with E = 1. mem_op must be 0 there: parse adds the unpacked x0 to its cached stack top and relies on x0 = 0 when PP = 0 (debug note in the log). spc = step(SPC - 0.5) guards against a caller's N1 on the first step, where E = 1 anyway.
**Limits.** Characters outside these classes (for example ! @ ; [ { and non-ASCII) reject. A digit after a space is never an intersection, so "=A:A 3:3" rejects and "=1 2" still rejects. A space between a name and '(' (=SUM (A1)) becomes an intersection with #NAME?. 1,687 parameters. **Multi-role weights.** X words initialised per token (README); SPC lives in N1 (word 28), unused by every other parse network, which pass it through.
