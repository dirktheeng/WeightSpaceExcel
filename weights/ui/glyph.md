# Weight block notes: glyph (129, entry) and glrow (175, glyph row and font ROM)

Hand-written, including the font (original bitmaps, see the v1 history in log/ui-agent.md). Not generated. The font block in glrow.wt was moved there from glyph.wt with a file copy of my own rows (logged); everything else was typed. Decisions U4 (font format), U7 (row blocks).

**Computes.** Draws or measures the 0-terminated string at P0 (one unit per word, at most 64 units). Args: T0 pen, T1 top, T2 colour, T3 clip right, T8 measure, T9 background (written behind ink in every drawn glyph row). Returns to (LR, LP) with T0 = final pen.
- glyph (129): one block read of 64 units at P0 (K = 64, N = 64); T5 idx = 0, T6 gy = -1.
- glrow (175, input 129 = state + buffer): each step draws one row of one glyph with one block write of ADV pixels (clipped), forwarding state and buffer (K = 128). gy = -1 means "start of a character": the row drawn is the glyph's first ink row f. After its last ink row l the pen advances and idx moves on. Measure mode: one step per character. The terminating step (unit 0, or pen >= clip in draw mode) writes nothing with K = 64 and returns.

**Derivation.** c = buf[idx] = sum_j u_j buf_j - sum_j u_(j+1) buf_j with u_j = [idx >= j] (two muls, exact for units). Char one-hot and font ROM as in v1: V = W [e_gy, 1] gives R + 10^12 ADV for every glyph; one-hot product picks one. f and l (first and last ink rows) are a typed 2 x 96 table read off the bitmaps. Mirror-free pixel order: s = R 10^(12 - ADV) has exactly 12 digits with the glyph's leftmost pixel at digit 11, so pixel j = digit 11 - j for every glyph. 10^(12 - ADV) = 10^9 + sum_k [ADV >= k](10^(12-k) - 10^(13-k)). q_k = ROUND(s 10^-k) (the lower digits are 0/1, so the fraction is at most 0.111.. and rounding is floor; error 1e-4). pixel_j = bg + d_j (fg - bg). N = min(ADV, clip - pen + 1) clamped, zero in measure mode, on the return step, or when the row is below y 799 (the address is then 0).

**Limits.** One size and style; at most 64 units per string; ink only (no anti-aliasing). Rows outside f..l are not written, so text must be drawn on a background already painted (every caller fills first).
**Parameters.** glyph 14; glrow about 4,900 (1,248 font, 192 f/l table, 260 for the 65-way unit selector, 288 one-hot rows). **Steps.** Draw: 1 + sum over characters of (l - f + 1) + 1 (a digit is 9 rows). Measure: characters + 2.
**Multi-role weights.** The font dense carries R (below 10^12) and ADV (multiple of 10^12), separated exactly (R < 1.2e11). **Tests.** test_glyph_measure_and_draw and every frame test.
